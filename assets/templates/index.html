NETGUARD v1.0.0

Intelligent Packet Sniffer & Network Threat Analyzer

NetGuard is an industry-grade Network Monitoring application designed for network administrators, SOC analysts, and security engineers. It leverages Scapy and PyShark to monitor raw layers, classify application protocols, verify checksum signatures, and execute a dynamic Stateful Intrusion Detection System (IDS). Featuring real-time dashboard visualization and forensic reporting engines, NetGuard serves as a modular platform for security analysis.

Key Capabilities

  • Live promiscuous-mode packet capturing
  • Stateful threat warning correlation (IDS)
  • ReportLab-compiled PDF Security Reports
  • GeoIP lookup coordinates resolver

Technology Stack

  • FastAPI & WebSockets
  • SQLite & Pandas
  • Scapy Engine Wrapper
  • Chart.js Render Engine
